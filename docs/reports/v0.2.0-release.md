# Research Explorer CLI 0.2.0

- Status: published
- Date: 2026-10-06
- Package source commit: `bc870830f7dab3f0d9d3e7c34bd5186c0e37d814`
- Package: `research-explorer-cli@0.2.0`
- Required Core: `research-explorer-core@1.6.1`

Version 0.2.0 resolves the seven usability findings collected during the first
real terminal trial. Interactive startup now exposes Pi's session selector and
a public Core Project picker. Project bindings live only in their Pi session;
new chats do not inherit the old global recent Project.

The default command surface includes `/project`, `/status`, `/mode`, `/next`,
`/actions`, `/doctor`, `/capabilities`, `/capability` and `/report`. Existing
`research-*` commands remain compatible. Manual mode is visually quiet.
Candidate mode generates three detailed model-backed directions immediately
and after each assistant answer, while `/actions` retains the deterministic
Core state-transition and human-gate path.

Acceptance includes 13 CLI tests, C0–C5 local gates, a real X-era TUI run,
public-registry installation, Project list/create queries, Linux and macOS CI,
and Core's 114-test suite.
