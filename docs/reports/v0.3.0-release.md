# Research Explorer CLI 0.3.0

- Status: published
- Date: 2026-10-08
- Package source commit: `bd2d4f65914bc94b11b2f20b5bb34fdda55b2932`
- Package: `research-explorer-cli@0.3.0`
- Required Core: `research-explorer-core@1.6.1`

Version 0.3.0 simplifies Research Explorer around one Pi session, one visible
chat history and lazily created Core research state. The startup flow uses a
single native Pi selector with an explicit new-session entry. Independent
Candidate and Auto modes are retired; `/next` is a normal chat turn.

The new `/run` workflow persists its goal, stage, budget and gate state in the
Pi session. It advances through evidence, hypotheses, protocol, experiments,
analysis, review and reporting without treating Core's early legal-action list
as a general planner. Existing scoped projects resume at the appropriate stage,
blocked runs can be replanned, and `/continue` handles scope approval in the
same task flow.

Acceptance includes 19 CLI tests, real Core C2 validation, C5 package upgrade
from and rollback to 0.2.0, package boundary and secret checks, npm registry
installation, and verification that the `latest` dist-tag resolves to 0.3.0.
